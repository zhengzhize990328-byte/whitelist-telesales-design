# 白名单电销系统产品需求文档（PRD）

**版本：** v1.0  
**日期：** 2026-07-26  
**状态：** 需求基线稿  
**适用国家：** 安哥拉、孟加拉、印尼
**产品类型：** 现金贷白名单电销转化系统  

---

## 1. 文档目的

本文档用于统一业务、产品、设计、研发、测试、数据、运营和质检团队对“白名单电销系统”的理解，并作为后续原型设计、技术方案、开发拆分、测试验收和上线评审的基础。

系统服务于已经过筛选的现金贷白名单客户，通过人工外呼推动客户完成注册、授信、借款和复借。系统不承担催收、逾期追踪、欠款提醒、还款承诺或追偿功能。

| 编号 | 决策项 | 已确认内容 |

| D-006 | 客户分配 | 系统自动分配，坐席不能挑选、领取或抢占客户 |
| D-007 | 通话录音 | 必须支持 |

| D-016 | 分配权重 | 第一期不配置优先级百分比或加权评分，采用资格校验、容量控制与公平轮询 |

## 3. 产品背景

现金贷业务会通过营销活动、历史客户、预授信筛选、复借资格筛选或其他内部方式形成可触达的白名单。当前需要一套统一系统，将白名单导入、数据校验、产品指定、自动分配、人工外呼、录音质检、客户跟进和业务转化状态串联起来。

系统需要解决以下问题：

1. 名单通过人工文件流转，容易重复、遗漏或缺少责任人。
2. 坐席自由挑选客户会导致优质名单集中、普通名单积压和绩效失真。
3. 客户的注册、授信、借款和复借状态未与电销任务形成闭环。
4. 缺少对通话过程、录音、结果和后续动作的统一记录。
5. 安哥拉、孟加拉和印尼的团队、语言、产品及数据需要相互隔离。
6. 运营人员无法清晰解释“客户为什么被分给某个坐席”。

## 4. 产品目标

### 4.1 业务目标

- 提高白名单从上传到首次触达的处理效率。
- 提高客户接通、注册、授信、借款和复借转化。
- 防止重复分配、重复联系和坐席挑单。
- 建立从名单到放款或复借的完整业务归因。
- 支持安哥拉、孟加拉与印尼独立运营。
- 建立可回放、可质检、可审计的通话过程。

### 4.2 产品目标

- 为坐席提供短路径、低学习成本的标准工作台。
- 为主管提供名单、团队、分配和异常处理能力。
- 为运营提供产品推广、规则配置和转化分析能力。
- 为质检提供录音、评分、问题标记和复核能力。
- 为管理层提供国家、团队、产品和坐席维度的经营数据。

### 4.3 核心成功指标

- 名单有效率
- 成功分配率
- 首次拨打完成率
- 接通率
- 有效沟通率
- 客户意向率
- 注册转化率
- 授信发起率
- 授信通过率
- 借款申请率
- 放款转化率
- 复借申请率
- 复借放款率
- 重复分配率
- 禁呼误触率
- 录音完整率
- 坐席任务完成率

首呼 SLA、保护期、最大触达次数等指标暂不固定数值，由后台配置。

## 5. 系统边界

### 5.1 本系统包含

- 国家、团队、坐席和产品配置
- 白名单文件上传
- 字段映射、校验、去重与隔离
- 推广产品指定
- 自动分配
- 安哥拉 Android 坐席 App
- 孟加拉与印尼共用的多国家 Web 坐席工作台
- Web 管理后台
- 电话呼叫和录音信息管理
- 通话结果和预约回拨
- 注册、授信、借款、还款状态和复借状态展示
- 录音质检
- 转化漏斗和绩效报表
- 禁呼管理
- 操作审计

### 5.2 明确不包含

- 逾期催收
- 欠款提醒
- 还款承诺管理
- 催收案件分配
- 催收话术
- 罚息或滞纳金展示
- 催收回款归因
- 自动审批或风控决策
- 贷款资金发放
- 还款扣款
- 贷款账务核算

还款相关数据仅作为客户生命周期和复借资格的只读信息，不触发催收流程。

## 6. 国家、语言和终端

### 6.1 国家隔离

系统中的以下对象必须带有国家标识：

- 客户
- 名单批次
- 产品
- 团队
- 坐席
- 电销任务
- 分配规则
- 通话记录
- 录音
- 质检任务
- 报表
- 禁呼记录

默认业务规则：

- 安哥拉名单只能分配给安哥拉团队。
- 孟加拉名单只能分配给孟加拉团队。
- 印尼名单只能分配给印尼团队。
- 安哥拉团队不能查看孟加拉客户。
- 孟加拉团队不能查看安哥拉客户。
- 任一国家团队不能查看或获取其他国家客户。
- 不允许跨国家自动分配。
- 平台超级管理员可按授权查看多国家配置，但所有访问必须记录审计日志。

### 6.2 语言

| 场景 | 默认语言 | 备选语言 |
|---|---|---|
| 安哥拉 Android App | 葡萄牙语（pt-AO） | 暂无 |
| 孟加拉 Web 坐席端 | 孟加拉语（bn-BD） | 英语 |
| 印尼 Web 坐席端 | 印尼语（id-ID） | 英语 |
| Web 管理后台 | 孟加拉语 | 英语 |

所有业务文案、状态、按钮、错误提示和话术模板必须通过国际化资源配置，不允许直接写死。

### 6.3 时间

- 数据库存储统一使用 UTC。
- 坐席端按所属国家时区展示。
- 名单上传、预约回拨、呼叫时间和报表筛选均按业务国家解释。
- 跨国家超级管理员查看数据时，需要明确显示时区。

## 7. 用户角色与权限

### 7.1 平台超级管理员

- 管理国家和系统级配置
- 管理国家管理员
- 查看多国家系统健康状态
- 配置全局权限模板
- 查看系统级审计日志
- 不默认拥有客户敏感信息明文权限

### 7.2 国家管理员

- 管理本国团队、坐席和产品
- 管理本国名单和分配规则
- 查看本国报表
- 管理本国禁呼名单
- 管理本国质检策略

### 7.3 运营主管

- 上传白名单
- 指定推广产品和负责团队
- 查看名单处理结果
- 发布和暂停分配规则
- 查看转化漏斗
- 处理未分配和异常任务
- 手动改派任务

### 7.4 团队组长

- 查看本团队坐席
- 配置坐席容量和工作状态
- 暂停或恢复坐席分配
- 回收和改派任务
- 查看团队绩效
- 查看被授权的录音和质检结果

### 7.5 电销坐席

- 查看系统自动分配给自己的任务
- 查看客户和主推广产品
- 发起外呼
- 查看话术
- 登记通话结果
- 创建预约回拨
- 查看自己的绩效
- 不得浏览完整名单池
- 不得挑选、领取或抢占客户
- 不得将任务转给其他坐席

### 7.6 质检人员

- 查看被分配的录音
- 播放录音
- 填写质检评分
- 标记问题
- 创建复核任务
- 不得修改客户业务状态
- 不得修改分配规则

### 7.7 数据分析/只读管理层

- 查看授权范围内的报表
- 查看聚合数据
- 是否允许导出由权限单独控制
- 默认不展示完整手机号和证件信息

## 8. 核心业务流程

### 8.1 主流程

```text
运营下载上传模板
→ 填写白名单
→ 选择国家、团队和主推广产品
→ 上传文件
→ 系统解析并映射字段
→ 数据校验
→ 文件内去重
→ 历史客户去重
→ 禁呼和业务状态检查
→ 有效名单进入待分配池
→ 自动分配引擎运行
→ 坐席收到下一位客户
→ 坐席外呼并生成通话记录
→ 系统保存录音
→ 坐席登记通话结果
→ 系统创建回拨或等待业务状态
→ 注册/授信/借款/还款/复借状态同步
→ 任务完成、进入后续推广或结束
→ 数据进入漏斗、绩效和质检
```

### 8.2 异常流程

- 文件解析失败：上传任务失败，显示错误原因。
- 部分行错误：有效行继续处理，错误行进入错误清单。
- 无法识别字段：要求运营完成字段映射。
- 客户重复：按照去重规则合并或隔离。
- 无可用坐席：客户进入待分配队列。
- 呼叫失败：保存失败原因，允许按规则重试。
- 录音缺失：生成录音异常告警。
- 业务状态同步失败：保留最近一次成功状态，并显示同步异常。
- 坐席离线：未处理任务按配置回收。

## 9. 功能需求

## 9.1 国家与组织配置

### FR-ORG-001 国家配置

系统应支持配置国家代码、名称、默认语言、时区、手机号格式、允许外呼时间和状态。

### FR-ORG-002 团队配置

系统应支持创建、编辑、启用和停用团队。团队必须属于一个国家。

### FR-ORG-003 坐席配置

系统应支持单个创建和批量导入坐席，并配置：

- 姓名
- 登录账号
- 所属国家
- 所属团队
- 支持语言
- 支持产品
- 工作班次
- 每日任务容量
- 同时持有任务上限
- 是否参与自动分配
- 账号状态
- 设备绑定状态

### FR-ORG-004 坐席工作状态

坐席状态至少包括：

- 离线
- 在线可分配
- 通话中
- 整理通话结果
- 休息
- 暂停分配
- 已下班

仅“在线可分配”的坐席可参与新客户分配。

---

## 9.2 产品配置

### FR-PRD-001 产品基础信息

产品必须配置：

- 产品 ID
- 产品名称
- 所属国家
- 产品状态
- 产品说明
- 额度范围
- 期限说明
- 面向客户的主要卖点
- 申请入口
- 适用客户条件说明

### FR-PRD-002 推广关系

一个客户可关联多个可推广产品，但一个电销任务必须且只能有一个主推广产品。

### FR-PRD-003 主推广产品变更

- 坐席不得自行变更主推广产品。
- 运营主管可变更。
- 变更必须填写原因。
- 变更前后产品及操作人必须写入审计日志。

### FR-PRD-004 备选产品

系统可以为任务配置备选产品。是否允许坐席向客户介绍备选产品由国家或团队规则控制。

## 9.3 白名单上传

### FR-UPL-001 上传格式

第一期支持：

- `.xlsx`
- `.csv`

### FR-UPL-002 上传前配置

上传人员必须选择：

- 国家
- 名单批次名称
- 名单来源
- 主推广产品
- 负责团队
- 名单有效期
- 分配开始方式：立即或指定时间

### FR-UPL-003 上传模板

系统应支持下载标准模板。模板应根据国家和产品显示必填字段及示例。

### FR-UPL-004 字段映射

系统应支持将文件列映射到系统字段，并保存常用映射模板。

### FR-UPL-005 上传预览

正式提交前展示：

- 文件总行数
- 可识别行数
- 缺少必填字段行数
- 文件内重复行数
- 预计新增客户数
- 预计更新客户数

### FR-UPL-006 数据校验

至少校验：

- 客户 ID
- 姓名
- 手机号
- 国家
- 产品
- 手机号格式
- 必填字段
- 字段类型
- 文件内重复
- 系统历史重复
- 禁呼状态
- 已存在有效推广任务
- 已申请或已完成目标产品

### FR-UPL-007 错误处理

- 有效行可以继续导入。
- 错误行进入隔离区。
- 用户可下载包含错误原因的文件。
- 修正后可重新上传。

### FR-UPL-008 上传历史

记录：

- 批次 ID
- 文件名
- 上传人
- 上传时间
- 国家
- 团队
- 主推广产品
- 总行数
- 成功数
- 重复数
- 隔离数
- 分配数
- 当前状态

### FR-UPL-009 幂等

同一个文件或同一批客户重复提交时，不得产生重复有效任务。

## 9.4 客户与白名单池

### FR-LEAD-001 客户唯一性

系统需要通过客户 ID、手机号及可用业务标识识别同一客户。具体去重优先级由国家配置。

### FR-LEAD-002 客户详情

客户详情至少展示：

- 基础资料
- 联系方式
- 国家和地区
- 名单来源
- 当前推广产品
- 可推广产品
- 历史电销任务
- 历史通话
- 最近通话结果
- 预约回拨
- 注册状态
- 授信状态和额度
- 借款状态
- 还款状态
- 复借资格和复借状态
- 禁呼状态

### FR-LEAD-003 名单状态

名单记录状态至少包括：

- 待校验
- 已隔离
- 待分配
- 已分配
- 跟进中
- 等待业务状态
- 已转化
- 未转化结束
- 已失效
- 禁止联系

### FR-LEAD-004 数据脱敏

手机号、证件号和其他敏感字段必须根据角色脱敏。坐席只能查看完成工作所需的信息。

## 9.5 自动分配引擎

### FR-ASG-001 自动分配原则

- 所有新任务由系统自动分配。
- 坐席不能查看未分配客户。
- 坐席不能选择、领取、交换或抢占客户。
- 坐席完成当前任务后，系统自动提供下一位客户。

### FR-ASG-002 分配触发

以下情况可触发分配：

- 名单上传完成
- 到达指定分配时间
- 坐席变为在线可分配
- 坐席完成当前任务
- 任务被回收
- 主管手动重新运行待分配队列

### FR-ASG-003 硬性准入

客户必须满足：

- 名单有效
- 未进入禁呼
- 未存在有效主负责人
- 未存在同一产品的有效推广任务
- 未完成当前主推广产品
- 国家和产品匹配
- 当前允许联系

### FR-ASG-004 坐席资格

候选坐席必须满足：

- 国家匹配
- 团队匹配
- 语言匹配
- 产品权限匹配
- 处于在线可分配状态
- 未超过任务容量
- 未被暂停分配

### FR-ASG-005 任务排序

第一期采用固定、可解释的队列顺序：

- 名单生成时间
- 名单上传时间
- 预约回拨时间
- 客户当前生命周期
- 最近联系情况

第一期不设置优先级百分比、综合评分或 AI 评分模型。预约回拨和原坐席保护使用独立队列规则处理。

### FR-ASG-006 坐席选择

候选坐席之间采用负载均衡和公平轮询，至少考虑：

- 当前任务量
- 剩余容量
- 当日已分配数量
- 是否有原坐席保护
- 坐席工作状态

### FR-ASG-007 原坐席保护

预约回拨和有效意向客户默认优先返回原坐席。保护期限由后台配置。

### FR-ASG-008 回收

坐席离线、退出班次、任务超时或主管手动操作时，可回收任务。回收规则由后台配置。

### FR-ASG-009 无法分配

没有合格坐席时，客户进入待分配队列，并记录具体原因：

- 无匹配团队

### FR-WAG-007 二次触达

通话结果为未接听、忙线、关机或客户要求稍后联系时，系统自动或按坐席填写时间创建二次触达任务：

- 未接听：按照国家规则生成建议跟进时间。
- 忙线：按照国家配置的最短间隔生成建议时间。
- 关机或不可达：进入下一个有效联系时段。
- 客户要求稍后联系：坐席必须填写客户指定时间。
- 系统建议时间允许坐席在合规联系时段内调整。

### FR-WAG-008 触达历史

“历史”页签即当前坐席的“今日已分配客户”列表，必须完整展示系统当天自动分配给该坐席的全部客户，不以触达结果、是否接通或是否已生成跟进任务作为过滤条件。每条记录至少包括：触达时间、客户、触达次数、结果、通话时长、备注摘要和系统创建的下一步动作。

历史数据字段只读，旧触达结果不得被坐席覆盖；修改旧结果必须通过有权限的异常修正流程，并保留审计记录。

今日已分配客户中的每条记录必须常驻展示“再次呼叫”入口：

- 无论上次结果为未接听、已接通、感兴趣或暂不需要，坐席均可再次呼叫。
- 点击后直接进入该客户呼叫页，不重新进入普通自动分配流程，不改变客户归属，也不构成挑单。
- 每次再次呼叫均生成新的独立触达任务和通话记录，并与原客户、原分配任务关联；旧记录保持不变。
- 通话结束后仍必须登记新的通话结果，保存完成前不得获取下一位客户。

### FR-WAG-009 跟进提醒

- 跟进前按国家规则提醒坐席。
- 到期后标记为待处理。
- 超过配置阈值后标记为已逾期。
- 坐席正在通话时不强制打断，任务持续保留在跟进中心。
- 所有时间按客户所属市场时区展示和校验。

跟进任务状态至少包括：待开始、即将到期、已到期、已逾期、处理中、已完成、已取消、已释放和已调配。

## 17. 验收标准

### AC-001 名单上传

运营可以上传标准 Excel/CSV，查看预览、有效数据、重复数据和错误原因。

### AC-002 产品指定

每个上传批次必须指定国家、团队和主推广产品，缺少任一项不能提交。

### AC-003 国家隔离

安哥拉、孟加拉和印尼名单只能被本国授权团队查看或获取，任一国家坐席都不能跨国访问客户。

### AC-004 自动分配

有效名单能够自动分配给符合国家、团队、语言、产品权限和容量要求的在线坐席。

### AC-005 禁止挑单

普通坐席无法访问待分配名单池，无法主动领取、交换或选择客户。

### AC-006 防重复

同一客户、同一主推广产品在同一时间不能产生两个有效主任务。

### AC-007 通话闭环

坐席可以从任务发起通话；通话结束后必须登记结果；结果能够触发回拨、等待状态或任务结束。

### AC-008 录音

成功接通的通话可以关联录音；录音缺失能够被系统识别和告警。

### AC-009 生命周期

客户详情能够展示注册、授信、借款、还款和复借状态及最近更新时间。

### AC-010 主产品

坐席能明确看到本次主推广产品，且不能自行修改。

### AC-011 禁呼

坐席登记“要求停止联系”后，客户立即进入禁呼，不能再次自动分配或拨打。

### AC-012 弱网

安哥拉 App 在网络中断时可以暂存当前结果，恢复后只同步一次。

### AC-013 质检

质检人员可以播放授权录音、完成评分、提交问题并反馈给对应坐席和组长。

### AC-014 审计

名单上传、规则修改、分配、回收、改派、禁呼和录音访问均可以追溯。

### AC-015 报表

运营可以按国家、团队、产品、坐席和名单批次查看从有效名单到放款和复借的漏斗。

## 20. 产品原则总结

1. 这是白名单销售转化系统，不是催收系统。
2. 名单由运营人员手动上传。
3. 上传批次必须指定主推广产品。
4. 系统自动分配，坐席不能挑单。
5. 安哥拉、孟加拉与印尼按国家隔离。
6. 安哥拉坐席使用葡语 Android App。
7. 孟加拉与印尼坐席共用多国家 Web，分别使用孟加拉语和印尼语。
8. 通话必须形成可追踪记录，并支持录音。
9. 客户状态覆盖注册、授信、借款、还款和复借。
10. 还款状态只用于生命周期和复借营销，不进入催收流程。
11. 所有分配、改派、录音访问和敏感操作均可审计。
12. 第一版不配置优先级权重，采用严格资格校验、容量控制和公平轮询。
13. 第一版优先保证名单准确、自动分配、防重复、通话闭环和业务状态同步。
